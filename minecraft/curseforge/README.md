# Curseforge

Minecraft modpacks from Curseforge.

## Environment Variables

| Variable | Default | Description | Example |
| -------- | ------- | ----------- | ------- |
| PROJECT_ID | | Curseforge project ID | `123456` |
| VERSION_ID | latest | Curseforge file ID, or `latest` | `123456` |
| API_KEY | | Curseforge API key | `123456` |

## Server Ports

| Port | Default | Description |
| ---- | ------- | ----------- |
| 25565 | 25565 | Minecraft |
