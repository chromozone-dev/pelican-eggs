# Valheim

Valheim is a Viking survival game.

## Environment Variables

| Variable | Default | Description | Example |
| -------- | ------- | ----------- | ------- |
| MODPACK_ID | | Thunderstore modpack id | `author/modname` |
| MODPACK_CODE | | Thunderstore modpack code | `123456` |
| MODPACK_STRING | | Thunderstore modpack string | `author-modname-version` |
